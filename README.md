# Разработка интернет-магазина

## Описание проекта

Данный проект представляет собой набор функциональностей для работы с сервисом вакансий hh.ru. 
Он включает в себя классы для подключения к API, работы с вакансиями, чтения/записи информации о вакансиях в JSON-файл. 

Цели проекта:
1) Разработка функционала для получения списка вакансий по определенным параметрам с сайти hh.ru.
2) Написание класса, который работает с вакансиями из списка, реализует методы валидации атрибутов, поддерживаает методы сравнения вакансий по зарплате.
3) Реализация класса для работы с файлами, который предоставляет методы чтения, записи данных, а также добавления и удаления вакансий, избегая при этом дублирования вакансий.
4) Разрабока вспомогательных функций, которые позволяют:
   - фильтровать вакансии по ключевым словам;
   - фильтровать вакансии по диапазону зарплат;
   - сортировать вакансии в порядке возрастания зарплат;
   - получать список топ-N зарплат;
   - выводить в консоль итоговую информацию по вакансиям.
5) Реализация функции взаимодействия с пользователем с применением вспомогательных функций и классов
